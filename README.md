# My ChatBot

## About
My ChatBot is a simple Python chatbot with a graphical user interface (GUI) built using Tkinter.

## Features
- Responds to user messages.
- Displays the conversation in a window.
- Includes a text box and Send button.
- Has a simple, colourful interface.

## Technologies Used
- Python
- Tkinter

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

   python chatbot_window.py

## Example
User: hi
ChatBot: Hello there!
